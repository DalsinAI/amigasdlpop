Put the Prince of Persia game data in this drawer (data): every file and
drawer of the data folder of an SDLPoP release
(https://github.com/NagyD/SDLPoP/releases, the "data" folder of the ZIP)
or of SDLPoP's source (https://github.com/NagyD/SDLPoP, folder data), with
the names as they are there: DIGISND1.DAT, GUARD.DAT, KID/, LEVELS/,
PRINCE/, TITLE/, font/, music/ and so on. It is the 1989 game's own data,
not SDLPoP's, so it is not part of this archive.
